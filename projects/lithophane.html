Lithophane Light Boxes

Personal design project · ongoing

3D PRINTEDCUSTOM CAD PER ORDERDOZENS MADE

This project started when I needed a personal, meaningful gift for a friend's special occasion. I discovered lithophanes — images that only reveal themselves when backlit — and decided to design a nightlight-style box around one, since the versions I found online were bulky, expensive, and required a wall outlet.

I designed a box in CAD with a slot for a 3D-printed lithophane panel and space for a battery-powered string of fairy lights. Getting it right took several iterations: the feet needed a very specific angle so the light would shine upward correctly, and I had to test different infill levels and fairy-light brands to get the weight balance stable.

Since making the first one, I've built dozens of these boxes as gifts and home-decor commissions, including customized versions like a Winnie-the-Pooh-themed box that supports multiple swappable pictures.
