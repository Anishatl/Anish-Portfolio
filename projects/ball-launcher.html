Precision Ball Launcher

Governor's Honors Program Engineering · Group project

ONSHAPE CADESP32 / ARDUINOBRUSHLESS MOTORS

Built as a personal project, this project called for a launcher precise enough to shoot a ½-inch ball 10–20 feet into a specific target window.

Design and iteration

I iterated through six OnShape prototypes before landing on a compression-wheel design using thermoplastic polyurethane wheels for grip and consistency, driven by dual brushless motors for reliable launch velocity.

Electronics and control

The launcher is controlled by an ESP32 running Arduino IDE, powered off LiPo batteries, with all wiring first mapped out on a breadboard before final assembly into a dedicated electronics box that kept wiring clean and serviceable.

I owned the design, material selection, all electronics and wiring, and final testing for the project.
