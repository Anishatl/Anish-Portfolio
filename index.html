About

I build data-driven strategy systems and machine learning tools — from predicting FIRST Robotics match outcomes across 100,000+ scouting data points, to training ensemble models that detect rare brain tumors in low-data settings.

My earliest engineering memory is my dad handing me a screwdriver in preschool to fix a TV remote — I've been taking things apart ever since. That instinct grew into a real practice through FIRST Robotics Team 1771, where I've spent four years turning competition data into strategy, and into a deepening interest in machine learning, from recurrent neural networks that read scouting reports to computer vision that reads my own cricket bowling mechanics.

A cricket bowling injury sent me down that second path: I taught myself computer vision and pose estimation to build an app that analyzes my bowling mechanics frame-by-frame, which let me return to bowling 25% longer and 6% faster before ultimately stepping back from the sport. That project is the clearest example of how I like to work — find the real problem first, then learn whatever it takes to solve it.

This fall, I'm at Georgia Tech to study Computer Engineering.
